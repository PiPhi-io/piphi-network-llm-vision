# LLM Vision 0.1.3 release evidence

Version `0.1.3` replaces the no-op sidecar command surface with bounded,
cancellable image-analysis jobs backed by an OpenAI-compatible provider adapter.
Media is accepted only by PiPhi broker identifier and is never retained in
state, events, diagnostics, or persistent storage.

Release acceptance requires:

- deterministic broker and provider fixtures with no account or private media;
- queue saturation, recovery, cancellation, provider failure, malformed input,
  media type, and size-limit tests;
- runtime-token authentication on every operational route;
- no credential, prompt, broker media identifier, URL, or raw bytes in state/events;
- locked dependency audit, `linux/amd64` and `linux/arm64` images, attestations,
  and exact-digest hardened execution as UID/GID `10001`;
- registry governance remaining `draft`, `unverified`, and rollout `0`.

Real providers, accounts, billing, private camera media, model quality,
accelerators, browser behavior, continuous video, and field compatibility remain
unverified.
