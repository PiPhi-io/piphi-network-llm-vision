# LLM Vision 0.1.2 release evidence

Version `0.1.2` supersedes `0.1.1` by pinning the base image, running as
UID/GID `10001`, and moving the SQLite idempotency ledger to the explicit
writable `/data/piphi` volume. The release retains immutable OCI provenance
labels and the trusted reusable GitHub release workflow.

Release acceptance requires:

- a `linux/amd64` and `linux/arm64` OCI index;
- GitHub provenance attestation verified against signer repository
  `PiPhi-io/.github`;
- exact-digest labels matching the source repository, release revision, and
  version `0.1.2`;
- healthy startup with a read-only root filesystem, dropped capabilities,
  `no-new-privileges`, and an initialized writable ledger volume;
- PID 1 running as UID/GID `10001`;
- registry governance remaining `draft`, `unverified`, and rollout `0`.

Provider accounts, credentials, private camera media, model quality, GPU or
accelerator hardware, browser behavior, and field compatibility remain
unverified.
